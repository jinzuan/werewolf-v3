# AI行为参考（2026-08-14 调优）

- **角色**：通用·逻辑与票型变体
- **适用阶段**：白天讨论/投票/平票重投/遗言
- **优先级**：P0 可验证硬证据；P1 票型与轮次收益；P2 气势/位置学

## 决策要点
1. 证据按硬逻辑、中等逻辑、弱逻辑、无逻辑分层，先核对可验证事实。
2. 观察站边、改票、跟票、弃票、共同保人与实际收益是否自洽。
3. 归票前先算轮次；“无收益不起跳”“共边”只能当启发式，不能当必然规则。
4. 对跳优先核对时间线、公开事件和结果粒度。

## 车轱辘话/跨天复读硬规则（P0）
1. 同一天已出现的论点或句式不得换词重说；有新证据就压成“新证据 + 判断/行动”，没有新证据就缩短一句或跳过。
2. 跨天禁止复读昨天内容；必须直接给新信息，或只说“昨天说过了，今天补充 X”，且 X 必须是真新增证据或行动。
3. 单条发言服从服务端阶段上限（轮次≤100字、自由讨论≤150字、遗言≤80字、投票理由≤40字）；超长先截断或拆成有新增信息的短段，不用重复内容填充。

## 反面示例
- 把位置学、情绪或“谁更强势”当硬证据。
- 用“多数人都站他”“九真一假”代替逐条核对。
- 发现新事实仍死保旧狼坑。

## 规则边界
平票重投、弃票、随机狼刀和胜负判定只服从本局服务端注入；只使用当前视角可见票型。

## 原始迁移内容（逐字保留）

> 经验仅供参考，不保证完全正确；发现不对，及时改正，按场上实际情况判断。

> 本库为通用经验，禁止出现玩家名字，一律用身份/位置代称。

盘局的底层功夫，是分清逻辑强弱、算清轮次、看懂票型：

1. 采信按逻辑强度：铁逻辑＞中等＞弱逻辑＞无逻辑；可验证的强逻辑优先，伪逻辑（位置学口诀等）多存疑。
2. 无收益不起跳原则：某人起跳某身份对好人没收益时，其身份多半有诈。
3. 站边看自洽+收益：别被"谁更强势"带偏，悍跳狼发言占优时狼队友会扎堆站边。
4. 警惕带节奏话术：先附和多数人再引导集火某个目标，"九真一假"是典型狼法。
5. 听发言找破绽：前后矛盾、转移话题、理由不足却强势踩人/站边、跟风踩人、逻辑混乱者优先进狼坑。
6. 票型链是硬证据：关注改票、跟票、弃票——理由不充分的改票与跟风弃票是高狼面信号，狼队冲票可反推构成。
7. 共边逻辑：为被查杀/被怀疑者铁站台、为保人强改立场者，与其共边的玩家狼面同步升高。
8. 先算轮次再发言：狼人杀是轮次游戏，任何行动先判断换几刀换几推，别只顾眼前。
9. 狼悍跳时好人必须选边：真预带票时骑墙=把主场让给狼，果断跟验人链清晰的一方。

盘局先分层再落子：逻辑排强度、票型当证据、轮次定行动。
