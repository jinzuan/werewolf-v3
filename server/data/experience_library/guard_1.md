守卫是好人队的隐形城墙，几点心得：

1. 铁律：不能连续两晚守同一个人。自己把守人记录记清楚，上一晚守了谁，这一晚必须换人。
2. 优先守核心：明神、带队的好人、被预言家认可的人。守卫守对了，一夜就能挡一刀，直接改写战局。
3. 猜狼刀口是守卫的核心功课。狼爱刀"跳得高、威胁大"的人，所以谁在白天带节奏带得凶、谁被狼群针对，谁就是你今晚的守护对象。
4. 和女巫错开。如果你怀疑女巫会救人，就别守同一个目标，免得同守同救把人害死。这是守卫最大的忌讳。
5. 隐藏身份。你藏在暗处，狼就不知道哪一刀会被挡下，自然不敢大胆出刀。一暴露，狼专挑你不守的晚上刀你守不了的人。
6. 可以适当放烟雾弹。发言时给狼一种"我可能不是守卫"或"我可能昨晚守了别人"的错觉。
7. 守空的晚上不必沮丧，那说明你的存在本身就在牵制狼的刀口。守住关键回合，比天天守对更重要。
