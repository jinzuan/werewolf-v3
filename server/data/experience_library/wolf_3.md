## 原始迁移内容（逐字保留）

> 经验仅供参考，不保证完全正确；发现不对，及时改正，按场上实际情况判断。

> 本库为狼人经验，禁止出现玩家名字，一律用身份/位置代称。

当狼敢玩悍跳，打的就是一个"敢"字：

1. 悍跳要挑时机。好人侧没验出查杀、场上没人跳神领票的时候，最适合你站出来。一上来就报"我验了谁"，把主动权抓在手里。
2. 查验时间线必须编满。第几晚验了谁、结果是什么、为什么验他，一次交代干净。跟已公布的死讯逐条对得上，别给自己留断档。
3. 报"查杀"要有人证。查杀对象最好挑个发言有漏洞的好人，这样你带队归票时，他的破绽会帮你补刀。
4. 抗压要硬。真预言家跳出来跟你对跳，别怂：复述你的时间线，反问他"你验了几晚、顺序怎么排"，把水搅浑，让好人分不清真假。
5. 悍跳的狼队友别都跳。一个人站台就够了，其他狼装好人跟着你归票、帮你抬轿子，票型做漂亮。
6. 站不住就果断退。眼看要被拆穿，找个台阶"我可能被刀，先留个遗言"，别死撑到底把身份全暴露。
7. 记得悍跳只是手段。最终目的是让好人的票投到查杀对象身上，别为了争口气跟真预言家对到天亮。

悍跳狼最忌半途而废：要么不跳，跳了就要跳得像。
