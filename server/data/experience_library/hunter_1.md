# AI行为参考（2026-08-14 调优）

- **角色**：猎人
- **适用阶段**：白天/放逐出局后的开枪/遗言
- **优先级**：P0 开枪资格；P1 合法目标与狼面；P2 藏身份

## 决策要点
1. 只有服务端授予 hunter_shoot 且目标合法时才行动；是否跳过看 skip_hunter_shot。
2. 当前 V3 为放逐出局触发开枪；被狼刀、被毒或其他方式带走不得自动开枪。
3. 枪口需要目标名、本轮具体证据和轮次收益；无证据且允许时跳过，不用空泛理由硬开枪。
4. 开枪、跳过、目标和结算结果按真实猎人行动写入可记录日志；真实发言不得标“[mock]”。
5. 遗言只使用该猎人可见的查验、用药、票型历史；“我不知道”不等于“系统无记录”。公开身份和枪口理由保持真实一致。

## 反面示例
- 把被狼刀/被毒自动当作有枪，或把“翻牌必须开枪”当硬规则。
- 因情绪、被踩或焦点位就盲枪。
- 把猎人行动日志遗漏或标成测试内容，或没有本轮证据仍强行开枪。

## 规则边界

> 经验仅供参考，不保证完全正确；发现不对，及时改正，按场上实际情况判断。

> 本库为猎人经验，禁止出现玩家名字，一律用身份/位置代称。

猎人的枪，关键是"开得值"：

1. 记住开枪的时机：被狼人刀死、被投票出局都可以开枪；被女巫毒死不能开枪。别弄混，那是送枪。
2. 枪口指向谁要想清楚。优先带走最像狼、最跳的人；如果实在没把握，宁可带走那个搅浑水的焦点位，也别乱泼一个无辜的好人。
3. 隐藏身份，别轻易暴露。狼人最怕明枪，你藏着，狼就不敢贸然刀你；你一亮出来，就成了集火目标。
4. 可以诈身份。装平民、装预言家都行，把狼人诈出来，让他们的刀口暴露在明处。但别把自己演死。
5. 被票时别慌。你出局前有枪，能带走一个人，这是好人队的保险。被票时把话说完，让好人知道你要带谁、为什么。
6. 开枪的目标身份不公布，只公布死讯——所以你要在开枪前用发言把理由讲清楚，否则别人看不懂你的枪口逻辑。
7. 别因为手里有枪就无所顾忌。枪是一票之力，不是免死金牌，活着比开一枪更有价值。

（团队协作）猎人天然有公信力，安全时机站出来带队能稳军心；被票/被刀前的遗言是最后一次帮好人定方向——把狼坑与归票意见交代清楚，让好人别在关键时刻散架。
