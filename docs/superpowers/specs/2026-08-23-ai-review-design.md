# AI 三轮复盘与私有经验迭代设计

日期：2026-08-23
范围：云端 V3 复盘管线（部署在服务器工作区）。

## 目标

- 开房复盘默认关闭；只有明确打开时才触发复盘任务。
- 对局结束后按三轮生成：阵营团队复盘、全局公开复盘、每个 AI 的个人复盘。
- 个人复盘只允许修改该 AI 本局实际抽到的经验实例；不改公共原始经验库，不把一个 AI 的更新合并给同职业其他 AI。
- 所有 API 凭据继续只从服务器部署环境读取，不进入房间快照、事件、复盘归档或前端。

## 数据与边界

1. 游戏会话为每个 AI 持久化 `experienceInstanceId`、经验资产 ID 和当前个人补充经验。按角色和座位稳定分配，恢复时不重新抽取。
2. 复盘归档保留这些实例的安全引用，供服务端生成器使用；前端只接收当前查看者有权看到的结果。
3. 团队轮只读取对应阵营可见事件；全局轮只读取公开时间线；个人轮只读取该 AI 可见事件及其自身历史发言。
4. 个人复盘输出不含任何玩家名/昵称；服务端再做名字过滤、证据事件校验和长度限制。
5. 个人经验写入服务端数据目录的隔离记录，提示词注入时仅给对应 `playerId + experienceInstanceId` 使用。既有按职业的历史心得继续作为兼容的共享参考，但新的个人更新不会进入共享池。

## 生成流程

- `AIReviewGenerator` 顺序调用同一部署级模型：好人团队、狼人团队、全局公开、每个 AI 自我复盘。
- 任一轮失败不影响对局结果；任务记录失败状态并支持重试。成功结果按轮次存储，旧版单条 message/insight 仍可读取。
- 无可用模型时保留规则/上帝视角归档，不伪造 AI 文案。

## 展示与权限

- 结果页按“阵营团队 / 全局公开 / 我的 AI 自我复盘”分组展示。
- 玩家只能看到公开轮、自己阵营团队轮和自己的个人轮；上帝视角可查看完整结果。
- 事件证据始终只返回当前查看者可见的事件引用。

## 验收

- 默认新房 `reviewEnabled === false`。
- 同职业两个 AI 的个人复盘写入两条不同隔离记录，互不出现在对方下一局提示词。
- 个人复盘含名字、无证据或跨权限事件时被丢弃。
- 三轮调用失败/重试、旧快照恢复、无模型降级、普通规则复盘和前端展示测试通过。
- 构建、类型检查、服务端测试通过后再重启云端服务。
